## WinDOT — Core Features

- 🌦️ **Weather** — Current conditions and forecasts
- 📋 **Clipboard History** — Quickly access copied text and items
- 📝 **Quick Notes** — Lightweight notes available from anywhere
- ⏱️ **Timer & Stopwatch** — Countdown timer and stopwatch
- 🧮 **Calculator** — Fast calculations
- 🎨 **Color Picker** — Screen color picker with magnified view
- 📸 **Screenshots** — Full-screen and selected-area capture
- 📂 **File Shelf** — Drag and drop files for temporary quick access
- 🔗 **Quick Links** — One-click access to frequently used websites
- 🔊 **Audio Controls** — Volume and media playback controls
- 🎨 **Customization** — Light/dark themes, adjustable dot size, and panel transparency

## Keyboard Shortcuts

**`Ctrl + Space`** — Open / collapse WinDOT

While WinDOT is open:

- **W** — Weather
- **N** — Notes
- **A** — Audio
- **C** — Calculator
- **T** — Timer
- **S** — Screenshot
- **P** — Color Picker
- **F** — File Shelf
- **L** — Quick Links

> **The main idea:** one tiny floating dot → click or shortcut → instantly access the tool you need.
